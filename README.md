# 🚀 AI CV Analyzer Pro

Một ứng dụng web mạnh mẽ được xây dựng bằng Python và Streamlit, tích hợp mô hình ngôn ngữ lớn Google Gemini AI để tự động phân tích, bóc tách và chấm điểm CV ứng viên dựa trên Yêu cầu công việc (JD).

## ✨ Tính năng nổi bật
- **Trích xuất dữ liệu thông minh:** Đọc và bóc tách văn bản từ file PDF (CV) nhanh chóng bằng `pdfplumber`.
- **Danh mục JD cấu hình sẵn:** Cho phép người dùng chọn các vị trí ứng tuyển phổ biến (Data Scientist, Computer Vision, Software Developer) thay vì phải nhập thủ công.
- **Phân tích siêu chuyên sâu:** Sử dụng AI để đánh giá Tech Stack, độ khó dự án và sự phù hợp với JD.
- **Giao diện trực quan:** Hiển thị điểm số Match Score, phân trang nội dung đánh giá bằng Tabs (Kỹ thuật, Dự án, Điểm mạnh/Yếu, Lời khuyên).

## 🛠️ Công nghệ sử dụng
- **Frontend/Giao diện:** Streamlit
- **Xử lý PDF:** pdfplumber
- **AI/LLM Engine:** Google Generative AI (Gemini 3.6 Flash)
- **Ngôn ngữ:** Python 3
